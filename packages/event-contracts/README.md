# Event Contracts Package

Package ini disiapkan untuk menampung helper runtime yang berasal dari `contracts/events`.

Rencana penggunaannya:

- generated validator untuk TypeScript
- shared event name constants
- optional helper untuk envelope parsing

Source of truth tetap berada di:

- `contracts/events`

Package ini sengaja masih tipis karena kita belum mengaktifkan code generation.
